# AI Document Assistant

An AI-powered assistant that lets users upload a PDF, extract its text, and ask questions about its contents.

## Features

- Upload PDF files
- Extract text from PDF pages
- Split extracted text into chunks
- Ask questions about the uploaded document
- Optional general-knowledge answers
- Built with Python, Streamlit, and Gemini

## How to run

1. Create and activate a Python virtual environment.
2. Install the required packages.
3. Add your Gemini API key to a `.env` file.
4. Run:

```powershell
streamlit run app.py
```

## Security

The `.env` file and API key are not included in this repository.
